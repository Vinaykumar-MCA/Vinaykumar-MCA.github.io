🚀 Deploy to Vercel — 5 Steps

1
Push to GitHub
git init → git add . → git commit -m "feat: initial build" → git push origin main
2
Import on Vercel
vercel.com → Add New Project → Import Git Repo → Select your portfolio repo. Vercel auto-detects Vite — no manual config needed.
3
Add Environment Variables
Settings → Environment Variables → add all 8 VITE_* keys. See docs/ENVIRONMENT_VARIABLES.md for full reference.
4
Deploy
Click Deploy. Vercel runs npm install --legacy-peer-deps → npm run build → serves dist/. Done in ~60 seconds.
5
Custom Domain (optional)
Vercel Dashboard → Domains → Add your domain → Update DNS at registrar → Update VITE_SITE_URL → Redeploy.
